## Getting the JDK

Go to [AdoptOpenJDK](https://adoptopenjdk.net)

Make sure that OpenJDK11 (LTS) and HotSpot are selected, and download the latest release for your computer (student laptops are Windows x64, or 64 bit Windows).

![JDK Version Selection]({{ "assets/img/jdk_nb/jvm_choose.PNG" | relative_url }})

Run the downloaded installer.  You will reach a screen that looks like this:

![JDK Option Selection]({{ "assets/img/jdk_nb/option_choose.PNG" | relative_url }})

Select the drop down next to `Set JAVA_HOME variable` and choose "Will be installed on local hard drive".
Continue on to finish the installation.

## JetBrains IntelliJ IDEA

Download the _community_ version of JetBrains [IntelliJ IDEA](https://www.jetbrains.com/idea/download).  
If you want, you can apply for an [educational account](https://www.jetbrains.com/community/education/#students) to get the Ultimate version for free, but we will not be needing the additional features. 

Run the installer, accepting the defaults; feel free to add the desktop and context menu shortcuts on the installer screen with those options.

When you open a project, you will be asked if you want to trust that project.
This will happen for every project in this class.

You may want to [set the directory you clone your assignments in as a trusted location](https://www.jetbrains.com/help/idea/project-security.html#trust_sources) so this box doesn't come up.
