## Unity Licencing

For this class, you will need to create a Unity ID.
You can accomplish this by visiting [Unity's Website](https://unity.com/), selecting the person icon at the top right of the screen, and choosing "Create a Unity ID".
Note: at no point should you pay for this software; we will be using Unity's personal licensing (though you can get the student licenses if you so desire.)

## UnityHub and a Personal License

Unity's Frameworks and versions are dealt with through UnityHub; you can download the installer [here](https://store.unity.com/download?ref=personal).

The first time you open UnityHub, you will be greeted with a screen that looks something like this:

![UnityHub First Run](/assets/img/unity_install/firstrun.png)

Using the person icon in the upper right corner, log in with the Unity ID you created in step 1.

At this point in the License Management tab,  it should say you have no Licenses; we need to use the "Activate New License" button to create a new Personal license (I chose "I don't use Unity in a professional capacity" when given the two options for personal license.).

We can now leave the Preferences window by using the Back arrow in the upper left of the UnityHub interface.

## Installing Unity

Select the Installs tab on the left hand side of the UnityHub interface; you should be greeted with:

![UnityHub interface](/assets/img/unity_install/installs.png)

Select the "Add" button, then select a release; we will use the Recommended Release (at the time of writing 2019.4.x (LTS))

![Unity Releases](/assets/img/unity_install/releases.png)

Hit Next, then think carefully about this next screen.

![Unity Modules](/assets/img/unity_install/modules.png)

If you are interested in using [Visual Studio Code and .NET Core](netcore-vscode.html) as your editors you do NOT need to install Visual Studio Community 2019 (though it won't hurt anything if you leave it selected).

I recommend leaving the Documentation option selected; other options are purely for your preference. We will not be targeting other platforms explicitly this semester, so we can skip those.
If it's something you'd like to experiment with, feel free to select some other options.
