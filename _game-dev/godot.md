## Downloading Godot

### Required Godot version: Standard Version 3.2 (not Mono version)

Download the required version of [Godot](https://godotengine.org/).
The student laptops are running 64-bit Windows; if you are using a personal computer download the appropriate version.

There is no install; all you need to do is download and extract the executable.
Put the executable wherever you want to run it from and create shortcuts as necessary.

Apparently you can also install through itch or Steam.

## Installing Export Templates

Export templates tell Godot how to build your game for different platforms; the list of supported platforms can be found on the Godot website.
Before we can use these templates, we must install them.

Either the first time you create a new project (or sometime), go to the Editor menu at the top of the program, and choose "Manage Export Templates".  The popup window should tell you the export templates are missing, so select "Download", and then an appropriate mirror (in my case, I had one option).
