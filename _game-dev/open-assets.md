This list will be constantly growing and evolving.  
In this class we will only be using assets (artwork, music, etc) we have a legal right to use.
Here I will list resources for freely available game assets.
Note that things like Humble Bundle often offer sales on game assets you can use

* [OpenGameArt](https://opengameart.org/)
* [Kenney.nl](https://kenney.nl/)
* [Itch.io](https://itch.io/game-assets/free)
* [r/gameassets](https://www.reddit.com/r/gameassets/)
* [CC Search](https://search.creativecommons.org/)

You can also design your own if you are an aspiring artist :)
